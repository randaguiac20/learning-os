    Learning OS¶

    A beginner → professional → expert journey through the machines that run modern software — computers and operating systems, Linux and the shell, networking, Git, containers, Kubernetes, performance, security, and finally AI/ML and the infrastructure that serves it.

    Built to a single promise: not just knowledge, but skill. Every topic pairs a short video, a set of standalone notes you never need to rewatch, a guided lab you can run in your browser, and a harder solo lab to prove you can do it alone.

    This course is free and public

    In the spirit of CS50, freeCodeCamp, and The Odin Project — no login, no paywall. Reuse the framework; the sources are cited so you can go deeper yourself.

    How each lesson is built (the 8-section loop)¶

    Every lesson follows the same evidence-based loop — one input → retrieve → apply easy → apply hard → self-test → schedule review — so learning compounds instead of leaking away:

    Section What you do Why it's there
    Why this matters See where the topic sits and what it unlocks Motivation + a mental hook
    Watch One short explainer + terminal casts — watch once A single clear input
    Key Notes Read the standalone notes The reference you keep; no rewatching
    Guided Lab Run the steps in a browser terminal Apply it with support
    Solo Lab Hit a harder goal with only hints Deliberate practice at your edge
    Self-Check Flashcards + explain-it-back Retrieval beats re-reading
    Mastery checklist Tick "I can…" — it gates progress Honest proof before moving on
    Review Come back on day 1 / 7 / 30 Spaced repetition locks it in

    The methods behind those sections have names and evidence — see How to learn.

    How to use this course¶

    You can read it like a book, or work it like a bootcamp. The curriculum was designed around a 4-hour study day; a sustainable daily rhythm is:

    Block Minutes What
    Review 30 Yesterday's flashcards + one older topic (spaced repetition)
    Theory 60 Watch once, then read the Key Notes actively
    Practice 105 Guided Lab → Solo Lab; type every command yourself
    Consolidate 45 Self-check, write 3 things learned, note tomorrow's first question

    Short on time? Do less, but keep the loop whole — a 40-minute session that watches, does one lab, and self-checks beats two hours of passive video. Progress is gated by the mastery checklist, not by the clock.

    The map (13 stages, 39 modules)¶

    Foundations → Linux & shell → tooling → programming & networking → containers → Kubernetes → performance → troubleshooting → security & ops → math & CS foundations → data & software engineering → cloud & AI domains → a woven capstone: a Full-Stack AI Service you build, serve, and deploy.

    Two things run in parallel

    Alongside the lessons you build a homelab — real infrastructure (containers → a Kubernetes cluster → GitOps → observability → GPU model-serving) using the same tools companies run in production. It becomes a public portfolio that showcases your skills for a high-pay job or a business. Every tier has a $0 starting point (your own laptop, or cloud free tiers).

    Learning OS is a personal study system, opened up so anyone can learn from it. The full lesson catalogue is published progressively — Module 01 is the complete, runnable pilot.
