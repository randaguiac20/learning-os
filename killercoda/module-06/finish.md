# Done — you can drive Vim now

In a few minutes you:

- Checked your Vim build and felt the **mode map** — `Esc` returns you home to Normal, every time.
- Wielded the grammar — `[count] verb motion/object` — and the **dot command `.`** to repeat a change.
- Changed text with **text objects** (`ci"`, `di(`) that work from *anywhere* inside the target.
- Ran file-wide **Ex** commands: `:g/^#/d` (grep's ancestor) and `:%s/\<old\>/new/g`.
- Wrote a small, **commented `~/.vimrc`** and learned to leave Vim on purpose (`:wq` · `:q!` · `ZZ`).

**Back on the lesson page:** do the *Self-Check* (recall + teach-back) and the harder *Solo Lab*
challenges — the `"0p` yank rescue, a macro applied with a count, and extracting lines with `:v`. Then
tick the *Mastery checklist*. When every box is honestly true, Module 07 (Tmux) — the session layer
around this editor — becomes current.

> interest — the same keystrokes, on your laptop today and inside a broken production node in Stage 8.**
