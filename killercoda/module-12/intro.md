# Programming Fundamentals — hands-on

You have a real Linux machine on the right, with **`python3`** already installed — an **interpreter**,
which is just a process that reads your source code and runs it. In the next few minutes you'll explore
values and types, then write small programs to files and run them: a **conditional**, a **loop**, a
**function**, and a program backed by a **dict** data structure. You'll finish by reading a traceback and
handling an error properly.

These are the **language-agnostic fundamentals** — variables, types, control flow, functions, data
structures. Python is just the vehicle; the ideas transfer to every language you'll ever learn.

**All work lives in a throwaway `~/learning/py/` workspace you create first** — nothing outside it is
touched.

> Tip: **type every program yourself** and **predict each output before you run it**. Predicting first is
> exactly where the mental model forms — watching the answer appear teaches almost nothing.
