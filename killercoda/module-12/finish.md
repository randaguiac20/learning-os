# Done — you can build now

In about half an hour you:

- Met the **interpreter** and saw that **every value has a type** — and that **variables are names bound to
  objects**, so `b = a` makes a second name for one object (**aliasing**) while `a[:]` copies.
- Wrote a **conditional** (`grade.py`) and learned that branch **order matters**.
- Wrote a **loop** (`fizzbuzz.py`) — iteration and selection combined over a half-open `range`.
- Wrote a **function** that **returns** a value and a **dict** that **counts by key** (`wordfreq.py`) — the
  two ideas most programs are built from.
- Read a **traceback bottom-up** and handled a **specific** error with an stderr message and a non-zero
  exit — the M5 CLI contract, kept in Python.

That's the language-agnostic core: **variables, types, control flow, functions, and a data structure.**
Everything ahead — real automation, network tools, AI — is these same ideas at scale.

**Back on the lesson page:** try the *Solo Lab* challenges (FizzBuzz without the `if`-ladder, the
mutable-default trap, list-vs-set timing), do the *Self-Check*, and tick the *Mastery checklist*. When
every box is honestly true, Module 13 (Python for Engineers) becomes current.

> The one-sentence takeaway: **M5 drew the line at 100 lines of bash; M12 crosses it — you now think in
> data structures and algorithms and can build real tools from nothing.**
