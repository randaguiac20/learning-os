# Data Structures & Algorithms — hands-on

You have a real Linux machine on the right with `python3` already installed. In the next few minutes
you'll **build the core containers by hand** — a stack, a queue, a hash-map counter — then prove the
costs with a stopwatch: watch an O(n) solution beat an O(n²) one, write a binary search and a sort that
agree with Python's own `sorted()`, **derive** dynamic programming by memoizing a slow recursion, and
trace BFS/DFS reachability on a graph.

**The law of this lab:** build every structure from scratch *before* trusting the built-in, and
**measure** every complexity claim — an asserted big-O you haven't timed is a guess. Everything is
standard-library Python (no `pip`), scoped to a throwaway `~/dsa-lab/` directory you create.

> Tip: **type every command yourself** — don't copy-paste. Typing is part of how the memory forms, and
> reading each line before you run it is the habit that catches bugs.
