# Python for Engineers — hands-on

You have a real Linux machine on the right with `python3` installed. In the next few minutes you'll
build a project the way engineers do: an **isolated virtual environment**, a package installed into it,
a small **typed module** with a generator, and a green **pytest** suite — then a tiny `argparse` CLI.

**Everything lives inside a throwaway `~/recall/` project, and nothing is installed into the system
Python** — that isolation is the whole point. A `.venv` is disposable by design; you'll even prove it.

> Tip: **type every command yourself** — don't copy-paste blindly. Typing is part of how the memory
> forms, and reading a command before you run it is a habit worth building now.

Click **START** to begin.
