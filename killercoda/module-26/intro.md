# AI Foundations — hands-on

You have a real Linux machine in the terminal on the right. In the next few minutes you'll open the AI
black box the curriculum's way — **bare-hands**, with plain numpy on a CPU. No GPU, no API key, no
gigabyte downloads.

You will:

- represent words as **vectors** and compute **cosine similarity** with your own numpy line (RAG's whole trick, naked),
- run a tiny **gradient descent** that fits a line and **watch the loss fall** — you will have trained a model,
- build a **toy tokenizer** (split → vocab → ids) and see why models count tokens, not words.

Everything lives in a throwaway `~/ai-foundations/` project. Calling a real LLM API is framed at the end as
the **"run locally with your key"** path — the same loop, more dials.

> Tip: **type every command yourself** — don't copy-paste. Typing the math is part of how the memory forms.

Click **START** to begin.
