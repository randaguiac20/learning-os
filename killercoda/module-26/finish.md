- Set up a **CPU-only numpy bench** — no GPU, no API key.
- Turned words into **vectors** and computed **cosine similarity** with your own line — RAG's ranking step, naked.
- Ran a **gradient descent** that fit a line and **watched the loss fall** — you trained a model, and felt the
