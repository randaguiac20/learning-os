# Bash Scripting — hands-on

You have a real Linux machine in the terminal on the right, and a **shell** (bash) at the prompt. In
the next few minutes you'll stop *typing* commands and start *writing* them into files that make
decisions, loop, package logic in functions, fail loudly, and clean up after themselves — the exact
difference between "works when I run it" and "safe when a timer runs it at 02:30".

You'll build every script in a **workbench** at `~/learning/scripts/`, plus a throwaway `/tmp/mine`
minefield for the quoting exercise. Nothing outside those directories is ever touched, and no step runs
as root.

> Tip: **type every command yourself** — don't copy-paste. Typing is part of how the memory forms, and
> the whole point of this module is quoting discipline you can only build by feeling it break.

Click **START** to begin.
