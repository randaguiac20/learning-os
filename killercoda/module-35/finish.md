# Done — you engineered, you didn't just code

In ~30 minutes you ran the real professional loop:

- Set up a **repo** and a **test runner** (git + pytest) — the bench every change is built on.
- Wrote a **failing test first** (RED), then the simplest code to pass (GREEN) — defining "correct"
  *before* the implementation.
- Caught a **genuine bug** with an edge-case test (a >100% discount going negative) and fixed it under
  the test's protection — the fix now stays as a **regression test**.
- Made **atomic commits** and **reviewed your own diff** against a code-review checklist — the human half
  of the quality gate.

That loop — test-first, small commits, review, a green suite that makes change fearless — is the
single highest-leverage habit in software engineering. It's what turns "it runs on my machine" into
software a team can trust and evolve.
