# Computer & OS Fundamentals — hands-on

You have a real Linux machine in the terminal on the right. In the next few minutes you'll read its
vital signs, watch a process live and die, and write your first script.

**Everything here is read-only and safe** — these commands *inspect*, they don't change anything. So
be curious: run them, read the output, and ask "why?"

> Tip: **type every command yourself** — don't copy-paste. Typing is part of how the memory forms.
