# Git — hands-on

You have a real Linux machine in the terminal on the right. In the next few minutes you'll build a Git
repository from nothing and practise the moves that make Git a thinking tool instead of a magic box:
**atomic commits**, **branching**, **a real merge conflict**, **recovery via the reflog**, and **your
own local "remote"**.

**Everything happens inside a throwaway `~/git-lab` repo you create** — it is all local, so you need
**no network, no GitHub account, and no remote server**. We simulate a remote with a local *bare* repo,
exactly the way GitHub works underneath.

First we set your identity so commits have an author. Git may already be installed; if not, the first
step installs it.

> Tip: **type every command yourself** — don't copy-paste. Typing is part of how the memory forms, and
> reading each command before you run it is the `status`-first habit in disguise.

Click **START** to begin.
