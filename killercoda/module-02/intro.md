# First Contact with the Terminal — hands-on

You have a real Linux machine in the terminal on the right, and a **shell** (bash) waiting at the
prompt. In the next few minutes you'll read your bearings, navigate the filesystem, build a sandbox,
manipulate files safely, and learn a command from its manual.

**Everything destructive happens ONLY inside a throwaway `~/terminal-lab/` sandbox you create** —
nothing outside it is ever touched. Read-only commands (`ls`, `cat`, `man`) inspect and change nothing,
so be curious.

> Tip: **type every command yourself** — don't copy-paste. Typing is part of how the memory forms, and
> pasting multi-line text can run commands before you've read them.

Click **START** to begin.
